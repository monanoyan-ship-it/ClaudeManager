Kurulum & Entegrasyon

1. API Durumu

ClaudeManager API sunucusu.

Kontrol ediliyor...

2. MCP Server Kaydi

Claude Code'un MCP tool'larini kullanabilmesi icin kayit gerekli. Bu komutu bir terminalde calistirin:

claude mcp add --transport stdio claude-manager -- node C:/Users/Ahmet/source/repos/monanoyan-ship-it/ClaudeManager/src/mcp-server.js

3. Hook Konfigurasyonu

Hook'lar otomatik loglama saglar. ~/.claude/settings.json dosyasina ekleyin:

setup-hooks.json icerigini ~/.claude/settings.json'a kopyalayin 

        


        

          
4. Claude'a Soyle

          
Herhangi bir projede Claude Code'a su komutu vererek pattern'leri okumasini saglayabilirsin:

          

            curl -s http://127.0.0.1:41847/api/projects
            
          

          

            
Ornek prompt'lar:

            

              http://127.0.0.1:41847/api/projects adresinden projeleri cek ve bu projenin pattern'lerini oku
              
            

            

              curl http://127.0.0.1:41847/api/projects/PROJE_ID/patterns ile pattern'leri oku ve uygula
              
            

            

              Bu projede ogrendigin kurali kaydet: curl -X POST http://127.0.0.1:41847/api/patterns -H "Content-Type: application/json" -d '{"project_id":PROJE_ID,"type":"rule","title":"KURAL_BASLIGI","description":"ACIKLAMA"}'
